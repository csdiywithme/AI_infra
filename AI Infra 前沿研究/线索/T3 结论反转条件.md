# T3 结论反转条件：速查

每条都是"X 在条件 C 下不再成立"。条件是我从一手来源的测量边界推出来的；带"推测"的是我的判断。

| 结论 | 反转条件 | 依据 |
|---|---|---|
| V4.1 式"全局 KV 长期落盘" | 需要精确复现滑窗状态；主机 DRAM 被其他状态占满 | [[A1 KV 状态变小之后#4. 什么时候结论会反转]] |

| 远端 prefill 提升 54% | 改为同成本比较 ⇒ 约 15% | 同上 |
| 请求结束应释放 KV | 多轮 agent、工具空档短 | [[A2 Agent 负载#4. 何时反转]] |
| KV TTL 有利 | 工具分钟级、显存紧、指标是单请求 TTFT | 同上 |
| PD 分离提升性能 | 目标是吞吐（vLLM 文档：不提升吞吐） | [[A3 分离的下一层#0. 旧基线与一条仍然有效的边界]] |
| AFD 提升 decode | scale-up 域小、prefill 主导 | [[A3 分离的下一层#5. 何时反转]] |
| prefill 专用芯片有价值 | agent 高命中负载 ⇒ prefill 占比小（推测，与 CPX 撤回一致） | [[A3 分离的下一层#3. 芯片按阶段分工：LPX 上、CPX 撤]] |

| 跨副本哈希能定位 SDC | 训练不是逐位确定的；融合 MoE EP kernel 掩盖通信签名 | [[A8 万卡故障与 goodput#4. 何时反转]] |
