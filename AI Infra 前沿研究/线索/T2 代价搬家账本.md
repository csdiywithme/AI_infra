# T2 代价搬家账本

讲座的第一条 invariant："优化不会消灭代价，只会移动代价。"下表把本笔记里每项新设计的"省下 / 新增"记成账。

| 设计 | 省下了 | 代价搬到了 | 详见 |
|---|---|---|---|
| Hybrid / 压缩 attention | KV 体积、长上下文 FLOPs | 状态种类、前缀复用粒度、短请求的固定状态 | [[A1 KV 状态变小之后]] |
| 跨机房 prefill（PrfaaS） | RDMA fabric 依赖、可用旧/异地算力 | 长度路由、带宽调度、同成本下收益缩小 | [[A1 KV 状态变小之后]] |
| KV 落盘 / G3.5 | 重复 prefill | 预取、SWA 小状态存储 vs 重算 | [[A1 KV 状态变小之后]] |
| KV TTL（agent） | 重 prefill、再排队 | HBM 被空闲会话占用、公平性 | [[A2 Agent 负载]] |
| P/D 角色在线切换 | P:D 比例失配 | 切换预热、graph 重捕获 | [[A3 分离的下一层]] |
| Attention/FFN 分离 | decode 专家 batch 太小 | M:N 比例、每层往返、依赖大 scale-up 域 | [[A3 分离的下一层]] |
| 融合 EP mega-kernel | 同步屏障、小 batch 通信暴露 | 硬件绑定、可调试性、弹性重建 | [[A4 MoE 通信融合]] |
| FP4 预训练 | 算力、显存、带宽 | 高精度保留层、Q/DQ、格式碎片、训推不一致 | [[A5 FP4 进入训练]] |
| 批不变 / TP 不变 kernel | RL 偏差、不可复现 | 1.04×–5× 性能（视方法与结构）、两份代码或受限 kernel | [[A6 数值一致性]] |
| 异步多版本 RL | rollout 长尾 | off-policy 偏差、更多比例与版本管理 | [[A7 RL 后训练系统]] |
| 增量 / P2P 权重同步 | 同步时间（53 s → 7 s） | RDMA 依赖、增量格式与量化耦合 | [[A7 RL 后训练系统]] |
| 副本级容错 | 全局重启 | 有效 batch 波动、容错 collective | [[A8 万卡故障与 goodput]] |
| 逐位确定训练 + 在线 SDC 检测 | 静默损坏扩散、离线诊断（约 3 次完整训练的算力） | 1–4% 开销、kernel 选择受限、需要健康副本 | [[A8 万卡故障与 goodput]] |
| 热备 / 原地更新 / 增量通信重建 | 重新排队与初始化（8K 卡重启 6.47 min） | 闲置备机、备件池估计 | [[A8 万卡故障与 goodput]] |
| 全局 KV 落 SSD + 滑窗 TTL + 有界重放（V4.1） | 共享前缀的重复 prefill | SSD 容量与保留承诺、近似重放 | [[A1 KV 状态变小之后]] |
| SRAM 型 decode 芯片 | decode 延迟 | 两套栈、容量规划、数值路径 | [[A9 硬件分工化]] |
| DSL 生成大部分算子 | 主机开销、可控归约 | 跨硬件移植、生成代码验证 | [[A10 Kernel 语言与编译栈]] |
| 层级 / 模型级 mega-kernel | launch 与同步开销（440 次调用 × 50 µs ≈ 22 ms 的量级） | 可调试性、动态形状、弹性 | [[A10 Kernel 语言与编译栈]] |
| AI 生成 kernel | 工程师时间 | 验证协议（声称 1.43× → 验证后 0.88×） | [[A10 Kernel 语言与编译栈]] |
| Engram 查表 | 等 FLOPs 下的知识容量、HBM（TP4 → TP2） | 主机 DRAM 180+ GiB（与 KV 卸载争用）、早层截止时间、大页与布局 | [[A11 条件记忆 Engram]] |
| 动态 CP / 动态 PP | 长度长尾的浪费 | 每步求解、代价模型误差 | [[A12 训练并行与数据管线]] |
| 分布式 Muon / 异步 PP | 重复 NS 计算 / 流水线气泡 | 所有者负载不均 / 绑定优化器 | [[A12 训练并行与数据管线]] |
| 多模态阶段图 | 阶段间等待、手写编排 | 连接器延迟、阶段比例 | [[A13 多模态与端侧推理]] |
