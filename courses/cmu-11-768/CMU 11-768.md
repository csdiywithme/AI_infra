# CMU 11-768 · AI Agents

> [!abstract] 课程定位
> CMU Fall 2026，Daniel Fried 和 Graham Neubig 主讲。关注 LLM 如何在多步任务中调用工具、管理上下文、与环境交互，以及怎样评测和训练这样的 agent。

## 学习顺序

| 主题 | 学习问题 |
| --- | --- |
| 工具调用、上下文、Skills 与记忆 | 一次模型调用怎样接入执行循环？工具返回、错误和历史状态怎样进入下一步决策？ |
| Coding agent 与评测 | 怎样定义任务成功？如何记录工具调用、失败原因和完成任务所需的时间与 token？ |
| Agent 训练 | 监督微调和强化学习分别使用什么轨迹与反馈？多步任务的奖励怎样分配到前面的决策？ |

可以从 [[CMU 11-763 - Lecture 10 - Incorporating Tools|11-763 第 10 讲 Tool Use]] 和 [[CMU 11-763 - Lecture 11 - Agents and Multi-Agent Communication|第 11 讲 Agents]] 接着读。做 coding agent 评测时，可以对照 [[05 评测与可信验收共同附录|算子优化 Agent 的评测与验收]]，看编译、数值正确性和性能测量怎样成为分开的验收条件。
