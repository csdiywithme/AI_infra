# AI Infra 学习笔记

以 Stanford CS336 为基础框架，结合 CMU 11-763，系统学习大语言模型与 AI Infra，重点关注 LLM 推理优化，并沉淀课程笔记、实验记录和求职准备材料。

## 课程主线

- **Stanford CS336 — Language Modeling from Scratch**：建立从模型、数据、训练到系统实现的完整基础。
- **CMU 11-763 — Inference Algorithms for Language Modeling**：重点学习推理阶段的生成算法、质量与延迟权衡、可控生成、inference-time scaling 及工程实现。

## 当前方向

- LLM 基础：模型结构、训练流程与 scaling
- AI Infra：计算、通信、存储与分布式系统
- 推理优化：生成算法、算子、量化、KV Cache、并行策略、调度、inference-time scaling 与 serving
- 工程实践：性能分析、复现实验与技术总结
- 求职准备：项目材料、面试知识点与岗位调研

后续目录将随着学习进度逐步建立，优先保持内容可复现、可检索、可持续更新。
